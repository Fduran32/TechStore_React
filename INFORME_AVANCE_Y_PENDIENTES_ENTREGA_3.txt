1. RESUMEN EJECUTIVO DEL ESTADO DEL PROYECTO
--------------------------------------------------------------------------------
Conforme a las indicaciones del docente, el proyecto se adaptó exitosamente a
un entorno 100% local, unificando la arquitectura en una solución robusta y de
estándar corporativo:

1. Backend Unificado (Spring Boot 4 / Java 17):
   Corre en puerto 8081 con Spring Security, autenticación por tokens JWT
   (JJWT 0.12.6), CORS global multipuerto y controladores CRUD para catálogo
   y stock.

2. Base de Datos Relacional (MySQL en Laragon):
   Opera en puerto 3306 bajo la base tienda_perifericos con tablas usuario y
   producto, datos reales y contraseñas encriptadas con BCrypt en UTF-8.

3. Frontend React 19 (Vite + Axios):
   Cliente web con interceptores Bearer automáticos, captura de 401,
   restauración de sesión en F5, catálogo en vivo y rebaja automática de
   existencias en bodega.
