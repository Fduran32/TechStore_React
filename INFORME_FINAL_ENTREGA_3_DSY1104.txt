1. RESUMEN EJECUTIVO DEL PROYECTO
--------------------------------------------------------------------------------
El proyecto TechStore Fullstack es una plataforma de comercio electrónico 
especializada en hardware y periféricos de alto rendimiento. Conforme a las 
indicaciones del docente, la solución se estructuró bajo una arquitectura 
desacoplada cliente-servidor 100% local:

• Backend Microservicio (Spring Boot 4 / Java 17 - Puerto 8081):
  Controladores REST, seguridad corporativa con Spring Security y tokens JWT
  (JJWT 0.12.6), CORS dinámico multipuerto y operaciones CRUD.
• Base de Datos Relacional (MySQL en Laragon - Puerto 3306):
  Base de datos tienda_perifericos con tablas usuario y producto, datos reales,
  claves foráneas, UTF-8 y contraseñas cifradas en BCrypt.
• Frontend Web (React 19 / Vite - Puerto 5173 / 5174):
  Single Page Application con Axios e interceptores Bearer, control de acceso
  por roles (RBAC), panel de inventario y descuento automático de stock en vivo.

4. FUNCIONALIDADES CLAVE IMPLEMENTADAS
--------------------------------------------------------------------------------
1. Panel de Inventario (/inventario):
   Tabla interactiva para visualizar productos, buscador en tiempo real, filtro
   por categoría, modales para crear nuevo producto (POST), editar (PUT),
   ajuste rápido de existencias (PATCH /stock) y eliminación (DELETE, solo Admin).

2. Control de Acceso por Roles (RBAC):
   - Administrador: Acceso completo a catálogo, compras y gestión total de inventario.
   - Vendedor: Acceso a catálogo, compras e inventario (crear, editar, stock), con
     botón de eliminar deshabilitado por seguridad.
   - Cliente: Acceso a catálogo, carrito y compras. Inventario completamente
     bloqueado con expulsión automática si intenta forzar la URL.

3. Descuento de Stock en Vivo:
   Al presionar "Pagar" en el carrito, se envían peticiones PATCH a MySQL
   descontando exactamente las unidades adquiridas.

4. Portada y Catálogo 100% Sincronizados:
   Tanto Inicio.jsx como Productos.jsx leen los productos y existencias reales
   desde la base de datos MySQL.

5. Nombres de Usuario Amigables:
   La interfaz saluda cordialmente con el nombre limpio de la cuenta
   ("Hola cliente / vendedor / administrador") tanto en la barra superior como
   en el historial de pedidos.
