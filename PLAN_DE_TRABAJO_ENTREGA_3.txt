1. RESUMEN EJECUTIVO
--------------------------------------------------------------------------------
El objetivo de la Evaluacion Parcial 3 es transformar la tienda online TechStore
(desarrollada en React en la entrega anterior) en una aplicacion Fullstack
empresarial completa. Para lograrlo, el frontend se conectara mediante Axios a un
backend desarrollado en Spring Boot (Java), respaldado por una base de datos
relacional MySQL y protegido por autenticacion basada en tokens JWT con control
de roles.

Adicionalmente, se implementaran dos microservicios independientes, despliegue
en la nube mediante AWS EC2 y una prueba de escalabilidad automatica (Auto Scaling)
cuando el consumo de memoria/CPU supere el 60%.


2. ARQUITECTURA GENERAL DEL SISTEMA
--------------------------------------------------------------------------------
1. Frontend (React 19 + Axios):
   Consume las APIs REST, inyecta el token JWT en cada cabecera con interceptores
   y restringe vistas segun el rol.

2. Microservicio 1 (Auth Service · Puerto 8081):
   Registro, login y firma de tokens JWT con roles (ADMIN, VENDEDOR, CLIENTE).

3. Microservicio 2 (Store Service · Puerto 8082):
   Catalogo de productos, categorias, boletas y detalle, conectado a MySQL.

4. Cloud AWS (EC2 + Auto Scaling):
   Instancia Ubuntu con regla de escalado automatico al 60% de uso de RAM/CPU
   monitoreado por CloudWatch.


3. MATRIZ DE ROLES Y PERMISOS (PAUTA DUOC UC)
--------------------------------------------------------------------------------
* ROL ADMINISTRADOR:
  - Alcance: Acceso total y sin restricciones a todo el sistema.
  - Vistas: Dashboard administrativo, gestion completa de usuarios, productos,
    categorias y ordenes.

* ROL VENDEDOR:
  - Alcance: Gestion operativa de catalogo y ventas.
  - Vistas: Visualizacion de lista de productos, detalle de productos y lista
    de ordenes de compra.

* ROL CLIENTE:
  - Alcance: Acceso exclusivo como comprador.
  - Vistas: Navegacion por el catalogo de la tienda, carrito de compras,
    pasarela de pago y seccion Mis Compras.
